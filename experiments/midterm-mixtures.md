# 영어 35단어 HMM 혼합 수 비교

## 설정과 결과

- 환경은 Apple M4 Pro, 48 GB, macOS 26.7.3, Python 3.9.6, NumPy 2.0.2. 새 패키지 설치 없이 시스템 Python을 사용했다.
- 수업 제공 Google Speech Commands v2 부분집합으로 학습 1,050개(단어당 30개), 공개 테스트 525개(단어당 15개)를 사용했다. 외부 데이터 및 증강은 사용하지 않았다. 테스트 정답은 인식 결과 생성 후 평가에 사용했다.
- 13차원 MFCC, 프레임 25 ms, 이동 10 ms. 음소당 3상태, 대각 공분산, 35단어 사전 및 양 끝 묵음 설정을 유지했다. 두 모델이 같은 테스트 특징을 사용했다.
- 제공 GMM 학습기의 1단계에서 단일 가우시안으로 10회 학습한 체크포인트를 기준 모델로 썼다. 제공 학습기의 2단계에서 각 성분을 둘로 분할한 뒤 10회 더 학습했다.

| 모델 | 누적 학습 반복 | 정답 / 전체 | 정확도 | 최종 `.hmm` 크기 | 525개 인식 시간 |
|---|---:|---:|---:|---:|---:|
| 1혼합 | 10 | 179 / 525 | 34.10% | 233,337 B | 90.61초 |
| 2혼합 | 20 | 187 / 525 | 35.62% | 437,682 B | 117.74초 |

2혼합과 1혼합의 차이는 정답 +8개, 정확도 +1.52%p, 모델 크기 1.88배, 인식 시간 1.30배다. 누적 학습 횟수가 달라 혼합 수와 추가 10회 학습의 효과가 함께 포함된다. 1혼합 20회 대조 실험 결과는 아래에 기록했다. 슬라이드의 크기는 1 KiB = 1,024바이트로 환산했다.

음성 1,575개의 MFCC 추출 시간은 4.65초였다. 두 모델을 순차 학습하는 과정은 531.98초였다. 1혼합 단계는 약 228초, 뒤이은 2혼합 단계는 약 304초다(전체 경과 시간과 두 체크포인트 저장 시각을 이용한 추정). 인식 시간은 학습 종료 후 같은 기기에서 1혼합, 2혼합 순으로 한 번씩 측정한 `/usr/bin/time -p`의 `real` 값이다. 모델 로딩, 525개 특징 읽기, 35개 단어 후보 인식, 결과 쓰기를 포함하고 MFCC 추출과 정답 채점은 제외한다.

각 모델의 결과 525줄 쌍에서 중복·누락 없이 원본 정답의 발화 ID와 일치하는지 검증했다. 별도로 센 정답 수와 제공 `eval.py`의 `Hits`도 일치했다. 2혼합의 오인식 사례로 실제 `dog` 발화 15개 중 6개를 `up`로 예측했다.

## 터미널 로그 읽기

학습 로그의 `950 / 1050 utterances processed`는 해당 회차에서 학습 음성 950개를 처리했다는 뜻이다. 제공 학습기는 10개마다 표시하는 `partial_ll`을 출력 후 0으로 되돌리지 않으므로 중간 값을 최근 10개의 정확한 평균으로 해석할 수 없다. 회차 끝의 `average log likelihood`는 별도 합계를 전체 발화 수로 나눈 값이다. 직렬 1혼합의 첫째·마지막 회차 값은 -5082.95, -4754.33이었고, 2혼합은 -4749.57, -4705.12였다. 인식 정확도는 이후 테스트 예측을 채점해 구한다.

## CPU 병렬 학습

`03_train_parallel_sc.py`는 OpenAI Codex의 도움으로 작성했다. 6개 프로세스에 학습 발화를 175개씩 나누고, 각 반복에서 모든 프로세스가 같은 HMM으로 전향·후향 확률 및 누적 통계량을 계산한다. 부모 프로세스가 평균·분산의 분자는 일반 합으로, 로그 공간에 저장된 점유량·전이 횟수는 로그합으로 결합한 뒤 모델을 한 번 갱신한다. 모델 파일 형식과 인식·채점 코드는 그대로 사용한다.

같은 초기 모델과 특징으로 1혼합 10회 + 2혼합 10회를 모두 실행했다. 직렬/병렬 실행을 순차 측정했고 특징 추출 및 인식은 학습 시간에서 제외했다.

| 학습 방법 | 전체 학습 시간 | 1혼합 정확도 | 2혼합 정확도 | 1혼합 크기 / 인식 시간 | 2혼합 크기 / 인식 시간 |
|---|---:|---:|---:|---:|---:|
| 제공 직렬 학습기 | 531.98초 | 34.10% | 35.62% | 233,337 B / 90.61초 | 437,682 B / 117.74초 |
| 6개 프로세스 병렬 학습기 | 95.72초 | 34.10% | 35.62% | 233,355 B / 93.56초 | 437,725 B / 119.39초 |

단일 실행의 학습 속도는 5.56배였다. 모든 학습 회차의 전이 확률·가중치·평균·분산·가우시안 정규화 상수를 직렬 모델과 대조한 최대 절대 차이는 5.03e-07였다. 두 혼합 설정 모두 직렬·병렬의 발화별 예측 525개가 전부 일치했다. 부동소수점 합산 순서 차이로 모델 JSON의 수치 문자열과 파일 바이트 수는 다를 수 있다.

저장소 루트에서 아래 명령으로 재현할 수 있다. 출력 폴더 이름은 새 이름을 지정한다.

```sh
cd bjasr_sc/03gmm_hmm
/usr/bin/time -p /usr/bin/python3 -u 03_train_parallel_sc.py --workers 6 --iterations 10 --output exp/parallel-replay
MODEL_ROOT="$PWD/exp/parallel-replay" PYTHON=/usr/bin/python3 sh ../../experiments/compare_mixtures.sh
```

측정 원본은 `bjasr_sc/03gmm_hmm/exp/midterm/parallel-train.log` 및 `bjasr_sc/03gmm_hmm/exp/mixture-comparison.S90Pdb`이다.

## 학습 횟수를 맞춘 혼합 수 비교 (2026-11-23)

기존 직렬 1혼합 10회 모델을 같은 직렬 학습기 구현으로 10회 더 학습했다. 기존 두 조건의 실측값을 재사용했다. 공통 조건은 학습 1,050개, 동일한 테스트 특징 525개, 13차원 MFCC, 음소당 3상태, 동일한 발음 사전이다. 외부 데이터·증강은 사용하지 않았다.

| 학습 조건 | 정답 수 | 정확도 | 모델 크기 | 인식 시간 |
